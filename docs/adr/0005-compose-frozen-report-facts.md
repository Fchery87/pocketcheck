# Compose frozen report facts in code

The research drafter receives the frozen game, research offer, evidence, gaps, and policy result. The application composes required gaps from the saved packet. A draft cannot remove them.

Model-pick explanations use a versioned format. The application renders contract terms, grade, and other authoritative numbers from the frozen pick. Evidence-number references resolve against the saved packet. A claim that uses a numeric evidence reference cites that evidence. Unknown or ambiguous references fail visibly while the pick remains saved.

Completed historical reports remain as saved. A pending response without a proven explanation format cannot be assumed to be a legacy response during recovery. It fails visibly instead of bypassing the current validation.
